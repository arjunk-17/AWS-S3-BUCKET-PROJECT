# AWS VPC Flow Logs Monitoring & Analysis

A hands-on AWS project demonstrating how to configure and analyze **VPC Flow Logs** for network monitoring and security analysis. The project sets up a VPC with public and private subnets, configures routing and an Internet Gateway, and captures network traffic using VPC Flow Logs.

The logs are stored in **Amazon S3** and analyzed to gain insights into network activity, detect potential security threats, troubleshoot connectivity, and improve network efficiency.

**Technologies:** AWS VPC • VPC Flow Logs • S3 • Route Tables • Internet Gateway
